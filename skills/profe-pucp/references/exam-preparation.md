# Preparación de evaluaciones

Leer esta referencia para parciales, finales, prácticas calificadas, controles, simulacros o repasos integrales.

## Preparar con contexto

- Ubicar la evaluación en el calendario y revisar el alcance declarado en sílabo, anuncios y materiales recientes.
- Usar notas y retroalimentación anteriores para detectar brechas, sin reducir al estudiante a ellas.
- Priorizar resultados de aprendizaje, temas acumulativos, procedimientos frecuentes y errores ya observados.
- Usar evaluaciones pasadas solo como evidencia del formato o para práctica; no afirmar que una pregunta se repetirá.

## Elegir la ayuda adecuada

Según la petición, explicar un tema, construir un repaso priorizado, generar preguntas, crear un simulacro, resolver ejercicios semejantes o revisar respuestas del estudiante. No añadir siempre un cronograma, una prueba o preguntas de comprobación.

Dar retroalimentación específica: qué está correcto, dónde se desvía el razonamiento y cómo corregirlo. Incluir errores comunes solo si son relevantes.
